# V0.1 Scope

## 目标

证明最小但完整的 compiler pipeline：

```text
GitHub + Local Git + Manual/Chat
  → Career Evidence
  → Candidate Career Facts
  → User-confirmed Facts
  → Career IR
  → Resume.md + GitHub Profile README.md
```

最大风险是 Evidence → Fact → IR 的领域模型是否干净，因此 V0.1 不把工作量投入到 UI、AI orchestration 或云基础设施。

## Available

- GitHub REST metadata source
- Explicit-directory Local Git source
- Manual/Chat source
- deterministic/mock fact extraction
- schema-validated replaceable `AIProvider` contract
- candidate/confirmed/rejected lifecycle
- many-to-many Fact ↔ Evidence provenance
- local SQLite repository abstraction
- versioned IR JSON export/import
- Markdown Resume renderer
- Markdown GitHub Profile renderer
- Alice synthetic golden path与 golden outputs
- domain、serialization、scanner normalization、renderer determinism tests

## Planned

- 更多 GitHub pagination 与增量 scan 策略
- richer user confirmation/rejection UI
- semantic duplicate/conflict workflows
- configurable source permissions and redaction review
- additional Sources（Pi、Claude、Codex、Blog、Social）
- Portfolio/Bio/Interview renderers
- HTML/PDF/DOCX outputs
- Web/Tauri clients

## Explicitly out of scope

Web Dashboard、Tauri Desktop、PDF、DOCX、LinkedIn/X integration、ChatGPT history scanner、Claude/Pi/Codex scanner、Vector DB、RAG、Knowledge Graph、Neo4j、Agent framework、MCP Server、OAuth、账户系统、云同步、SaaS backend、复杂权限模型、自动发布 GitHub README、自动覆盖真实 GitHub Profile。
